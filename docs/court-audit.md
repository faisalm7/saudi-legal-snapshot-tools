# Reviewed court publications

The release selects 480 source publication records with 481 complete judgment/appeal body components: 441 current Supreme Court API records, 10 current other-court API records (11 components), 28 historical Supreme Court PDF transcriptions and one newly retrieved current PDF transcription. The source record is the counting unit; this is not a claim of 480 unique disputes.

Independent AI-assisted review read 514 complete source-version contexts for 513 locators. The initial strict 486-locator Supreme cohort was resolved through current bodies or historical PDFs; the 22 other-court candidates were reviewed separately. Thirty current contexts remain private for actual personal financial/family/home, identifying or unclear-role details; three complete-body aliases are represented only as relations. One unmasked historical version remains private while a separately retrieved, publisher-masked current version of that locator is selected. No reviewer-added privacy redactions or substitute legal wording were used.

Current API responses are authoritative for the 451 API-selected records. All populated judgment and appeal fields are retained, with exact component hashes/offsets; empty separate facts/reasons fields are not invented. Native comparisons checked 457 current Supreme PDFs and all 22 other-court PDFs. Selected Supreme pages, every page of the 10 approved other-court records (17 pages), all 29 historical sources (30 pages), and the new current PDF page were visually inspected. Five approved API records have no retrieved current PDF and carry explicit null/quality evidence.

PDFs can reveal names, docket identifiers, cities, dates or judicial signatures absent/masked in the API, or clip text under layout controls. The API wording is preserved and differences flagged; PDF-only information is not inserted. Native font/ligature and RTL numeric-order differences prevent a blanket literal-equivalence claim. The historical glyph/date/punctuation/negation correction ledgers were replayed and every page read. Twenty original historical PDF byte hashes were independently rechecked; nine cloud-unavailable rechecks rely explicitly on the primary builder's hash/native/render receipts plus independent complete page inspection. Historical capture time remains unknown, not inferred from PDF creation metadata.

Publisher masks do not certify anonymity. Official judges are retained as public officeholders. A legal entity/trade name and clearly professional representative/expert roles were assessed in their actual contexts, with flags where unmasked; they were not automatically treated as private litigants or anonymous. The dataset contains no raw PDF, private review context, deferred/alias body or nested raw judicial HTML.

A broader 38,011-path court inventory was enumerated, but file counts, byte-processing checkpoints and distinct publication counts are separate. No whole-inventory content-completion or all-court coverage claim follows from this selected release. Qadha/grievance compilations are not included. The [MOJ source-wide rights basis](source-rights.md) remains separate from these privacy/fidelity decisions.
